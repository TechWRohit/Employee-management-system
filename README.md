# Employee Management System

A console-based Employee Management System developed using Java, JDBC, MySQL, and Maven.

## Features
- Add new employees
- View all employees
- Search employees by ID
- Update employee details
- Delete employees

## Technologies Used
- Java
- JDBC
- MySQL
- Maven
- IntelliJ IDEA

## Database Setup
1. Install MySQL.
2. Create a database named `employee_management`.
3. Create an `employees` table with the required columns.
4. Configure the database connection using environment variables.

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Configure the MySQL database.
4. Set the `DB_PASSWORD` environment variable to your MySQL password.
5. Run `Main.java`.

## Learning Outcomes
- Java programming and methods
- JDBC database connectivity
- SQL CRUD operations
- PreparedStatement and ResultSet
- Maven dependency management
